\item[\textbf{Problem 2}]
Git'ing around (%
    \href
        {https://training.github.com/downloads/github-git-cheat-sheet.pdf}
        {https://training.github.com/downloads/github-git-cheat-sheet.pdf}%
). For steps b--g run `git log' after the needed commands and take a screenshot.
What were the commands needed to complete these steps? What is the difference
between a commit and a push?

\begin{enumerate}
    \item Create a blank repository on GitLab
    \item Clone the repository on your local machine
    \item Add a file to the repository (+ commit and push)
    \item Create a branch (test-branch)
    \item Add a new file to the branch (+ commit and push)
    \item Merge test-branch to master (+ commit and push)
    \item Add a tag \code{feature a} to the latest commit \\
          (%
            \href
                {https://docs.gitlab.com/ee/user/project/repository/tags/}
                {https://docs.gitlab.com/ee/user/project/repository/tags/}%
          ). Note that tags will be used to keep track of substantial
          contributions to your group labs.
\end{enumerate}

\Solution

\begin{enumerate}
    \item To create a blank repository, navigate to
          \href
            {https://gitlab.com/dashboard/projects}
            {https://gitlab.com/dashboard/projects} or click \textbf{Projects}
            on the left. Click \textbf{New Project}, then \textbf{Create Blank
            Project}. Specify the project name and group or namespace, change
            the visibility level (private by default), and configure any other
            options, such as creating the repository with a README file,
            enabling SAST, or enabling Secret Detection. Finally, click
            \textbf{Create project}.
            \\
            \begin{minipage}{\linewidth}
                \centering
                \includegraphics[width=0.8\linewidth]{problem-2-1.png}
                \captionof{figure}{Blank Project: \code{test-repository}}
            \end{minipage}

    \item To clone a repository to a local directory, use the command
          \code{git clone <URL>}. In my case, the URL was
          \code{git@gitlab.com:EvilCheetah/test-repository.git}. \\
          \begin{minipage}{\linewidth}
                \centering
                \includegraphics[width=0.8\linewidth]{problem-2-2.png}
                \captionof
                    {figure}
                    {%
                        Cloning Repository: \code{git clone} followed by
                        \code{git log}%
                    }
          \end{minipage}

    \item To create a file, I used \code{touch main.py}.
          To stage the file for committing, I used \code{git add .}.
          To commit the changes, I used \code{git commit -m <MESSAGE_BODY>}.
          To push the commit to the remote repository, I used
          \code{git push origin main}.
          \\
          \begin{minipage}{\linewidth}
                \centering
                \includegraphics[width=0.8\linewidth]{problem-2-3-1.png}
                \includegraphics[width=0.8\linewidth]{problem-2-3-2.png}
                \captionof
                    {figure}
                    {%
                        File Creation, committing and pushing%
                    }
          \end{minipage}

    \item To create a new branch and switch to it, I used
          \code{git checkout -b test-branch}.
          \\
          \begin{minipage}{\linewidth}
                \centering
                \includegraphics[width=0.8\linewidth]{problem-2-4.png}
                \captionof
                    {figure}
                    {Creating and Switching to \code{test-branch}}
          \end{minipage}

    \item To create a file, I used \code{touch test.py}.
          To stage the file for committing, I used \code{git add .}.
          To commit the changes, I used \code{git commit -m <MESSAGE_BODY>}.
          To push the commit to the remote branch, I used
          \code{git push origin test-branch}.
          \\
          \begin{minipage}{\linewidth}
                \centering
                \includegraphics[width=0.8\linewidth]{problem-2-5-1.png}

                        File Creation, Committing and Pushing%

    \item To merge the branch, I first checked out the \code{main} branch using
          \code{git checkout main}. I then merged \code{test-branch} into
          \code{main} using \code{git merge test-branch} and pushed the changes
          using \code{git push origin main}.
          \\
          \begin{minipage}{\linewidth}

    \item To create an annotated tag, I used the following command:
          \\
          \code{git tag -a feature-a -m "feature a"}.
          \\
          To push the tag to the remote repository, I used the following command:
          \\
          \code{git push origin main --tags}.
          \\
