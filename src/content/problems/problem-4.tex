\Solution

\begin{enumerate}
    \item In the build stage, the author attempted to automatically compile a
          C++ file using the \code{g++} compiler.
          \begin{itemize}
                \item File being compiled: \code{helloworld.cpp}
                \item Executable being created: \code{mybinary}
                \item The code in \code{./runmytests.sh} contains a test suite,
                      most likely end-to-end (E2E) tests, that runs against the
                      binary compiled during the build stage.
          \end{itemize}
