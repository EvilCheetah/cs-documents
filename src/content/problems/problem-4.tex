\item[\textbf{Problem 4}]
Describe the differences between symmetric crypto and asymmetric crypto.

\Solution

Symmetric cryptography uses a single shared key for both encryption and
decryption. Because it is computationally faster, it is ideal for encrypting
bulk data. However, it requires both parties to securely agree on and exchange
the key beforehand.

In contrast, asymmetric cryptography uses a mathematically linked key pair: a
public key that can be openly distributed for encryption, and a private key kept
secret for decryption. While slower, it solves the key distribution problem.
Therefore, asymmetric cryptography is typically used for secure key exchanges,
digital signatures, and encrypting smaller amounts of sensitive data.
