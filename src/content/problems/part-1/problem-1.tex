\item[\textbf{Problem 1}]
Consider a single AN used for classification in a 2D space with an
augmented vector as discussed in class. That is, this AN has a constant input of
1 as its \textit{0th} input (which is multiplied by $w_{0}$) as well as inputs
$x_{1}$ and $x_{2}$ which are multiplied by $w_{1}$ and $w_{2}$, respectively.
This AN is a summation unit (SU) and its activation function $f$ is a step
function:
    
\[
f(net) = \begin{cases} 
1, & net \ge 0 \\ 
0, & net < 0 
\end{cases}
\]

Given the weights $w_{0}=0.5$, $w_{1}=1.0$, $w_{2}=-0.3$, \textbf{draw} this AN.
