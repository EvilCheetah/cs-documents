\item[\textbf{Problem 7}]
Let's modify the protocol from the previous problem so that Bob (still
stateless) sends both a challenge, and a challenge encrypted with a key
$K_{Bob}$ that only he knows. Is this protocol secure? Why?

\begin{minipage}{\linewidth}
    \centering
    \includegraphics[width=0.8\linewidth]{problem-7-diagram.pdf}
    \captionof{figure}{Modified Mutual Authentication Protocol Sequence Diagram}
\end{minipage}

\Solution

The protocol is \textbf{NOT} secure. It is also vulnerable to a \textbf{replay
attack}, which compromises the authentication between the two parties. Although
Bob attempts to handle his statelessness by sending an encrypted state token
alongside the challenge, he still cannot verify the freshness of the response.
An attacker can replay a previously captured message containing the old token
and encrypted challenge to trick Bob into believing they are Alice.
