\item[\textbf{Problem 8}]
What are the differences between symmetric and asymmetric key crypto?

\Solution

Symmetric-key cryptography uses the same shared secret key for both encryption
and decryption.

Asymmetric-key cryptography uses two related keys: a public key
and a private key.

Symmetric cryptography is usually faster, while asymmetric
cryptography is slower but useful for secure key exchange, authentication, and
digital signatures.
