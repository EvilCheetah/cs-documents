\item[\textbf{Problem 1}]
Create an account on gitlab, ssh-keys on your local machine (and the gpels), and
upload the public keys to gitlab. What were all of the commands needed to
complete these steps?

\begin{enumerate}
    \item Create a gitlab account (if you don't already have this)
    \item Generate ssh key pairs (%
          \href
            {https://docs.gitlab.com/ee/user/ssh.html}
            {https://docs.gitlab.com/ee/user/ssh.html}%
    )
    \item Add public ssh keys to your gitlab account
          \\
          (%
          \href
            {https://docs.gitlab.com/user/ssh/#add-an-ssh-key-to-your-gitlab-account}
            {https://docs.gitlab.com/user/ssh/\#add-an-ssh-key-to-your-gitlab-account}%
          )
\end{enumerate}

\Solution

To create SSH keys, I can run \code{ssh-keygen} on macOS, Windows, or Linux. The
system will prompt me for an optional passphrase. Once generated, the keys are
stored in the \code{~/.ssh} directory. To add them to my GitLab account, I need
to copy the contents of the public key (\code{.pub}) file and paste them under
\textbf{Account Preferences $\rightarrow$ Access $\rightarrow$ SSH Keys}.
