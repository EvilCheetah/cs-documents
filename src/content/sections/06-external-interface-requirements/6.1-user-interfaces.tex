\subsection{User interfaces}

\subsubsection{User Interface Components}

\begin{itemize}
    \item \textbf{Mentor Dashboard:} Facilitates event creation and management.
    
    \item \textbf{Mentee Personal Calendar:} Provides a specialized view of
    eligible events and currently RSVP'd events.
    
    \item \textbf{Super Admin Interface:} Allows a designated user to promote or
    demote user roles.
    
    \item \textbf{Event details/RSVP Page:} Displays event specifics and
    information, allowing for registration or viewing the RSVP list.
\end{itemize}



\subsubsection{Interface Characteristics}

\begin{itemize}
    \item \textbf{Centralized navigation:} The application will have a central
    portal for all event planning and communication.
    
    \item \textbf{Interactive Calendar View:} The mentees will have access to an
    interactive calendar where clicking a date displays information about the
    event.
    
    \item \textbf{Standard buttons:} Standard buttons for event management and
    interaction for both mentees and mentors.
\end{itemize}



\subsubsection{GUI Standards}

\begin{itemize}
    \item \textbf{Responsive Web Design:} The website should be compatible with
    modern operating systems and devices.

    \item \textbf{Error message display standards:}
    \begin{itemize}
        \item \textbf{Time Conflict Displays:} If a mentee attempts to join an
        event that overlaps with an existing event scheduled, the system will
        display an error message.
        
        \item \textbf{Mentor Notifications:} Notifications are automatically
        sent to mentors when a mentee cancels an event or when a scheduling
        conflict requires mentor approval.
    \end{itemize}
\end{itemize}
