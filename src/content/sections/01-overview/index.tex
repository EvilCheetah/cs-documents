\section{Overview}

The {\ClientName} {\ClientProject} is a web application that gives the
{\ClientName} program at the {\ClientOrganization} a single place to manage all
their events. Currently, mentors manually send separate emails and text messages
to different mentee cohorts, which is very time-consuming and prone to mistakes.
The new application fixes that issue by letting mentors create events, choose
which mentees can see them, and automatically send reminders to mentees. Mentees
get a personal calendar that only shows events meant for them, and signing up is
as simple as clicking a button. If a mentee tries to sign up for overlapping
events, the application detects the conflict, shows the events side by side, and
asks the relevant mentor to approve before anything changes. Once a mentee signs
up, the event is added to their Outlook or Google Calendar, and mentors are
notified whenever a mentee cancels.
