\subsection{Performance}

\begin{itemize}
    \item \textbf{PERF-1:} When a user logs in, application shall display their
    respective interfaces (Mentee Personalized Calendar or Mentor Dashboard)
    within 2 seconds.

    \item \textbf{PERF-2:} When an event is created, application shall display
    it on eligible mentees' personalized calendars within 2 seconds.

    \item \textbf{PERF-3:} When mentor edits an event, application shall update
    mentees' personalized calendars within 2 seconds.

    \item \textbf{PERF-4:} When mentor deletes an event, application shall
    remove it from mentees' personalized calendars within 2 seconds.

    \item \textbf{PERF-5:} When mentee RSVPs or un-RSVPs from an event,
    application shall update their personalized calendar within 2 seconds.

    \item \textbf{PERF-6:} When mentee requests approval to RSVP a
    time-conflicting event, a notification shall be sent to mentor's dashboard
    within 2 seconds.
\end{itemize}
