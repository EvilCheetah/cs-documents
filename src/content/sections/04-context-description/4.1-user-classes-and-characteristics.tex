\subsection{User Classes and Characteristics}

There will be three user roles: mentees, mentors, and a super admin. Mentees
will have access to a calendar that shows the events they are eligible for.
Mentees are lower-classmen with access to the product. Mentees will have the
lowest security and privilege levels. Mentors will have access to create events
and invite mentees and other mentors to the event. Mentors' security access is
the same as mentees', with higher privileges, as they can create events and
control the invite list. A super admin is a single person with a special ID who
has the privilege to promote or demote user roles from mentee to mentor. The
super admin will have the highest level of security access and privileges. The
super admin has the highest level of education, as they are the head of the
student organization.
