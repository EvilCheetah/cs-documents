\subsection{Major Features}
\label{subsection:major-features}

Mentors can create events with different visibility settings for mentees:
invitation-only, open to everyone, or cohort-specific. Mentees can only view and
join events relevant to them. When viewing events, information about event
title, event description, date, time, and location will be displayed. Mentees
also have access to the RSVP list to see the status of other attending mentees.
If a mentee attempts to join an event that conflicts with their current
schedule, an error message is displayed, and a notification is sent to their
mentor. This scheduling conflict can be overridden by mentor approval. When a
mentee joins an event, the event must be synced with their personal Google
Calendar or Microsoft Outlook Calendar.
