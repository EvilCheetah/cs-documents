\subsection{Project Scope}

The {\ClientName} {\ClientProject} will centralize all program event operations
into a single application for mentors and mentees. As mentioned in
\hyperref[subsection:major-features]{Section \ref*{subsection:major-features} -
Major Features}, mentors can create events with different visibility settings,
and mentees can see and join events relevant to them. Ultimately, the
{\ClientName} Schedule Planner will improve communication efficiency,
communication clarity, and reduce the burden that mentors currently have from
manually planning events.
