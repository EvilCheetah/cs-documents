\item[\textbf{Exercise 20.2-7}]
There are two types of professional wrestlers: ``faces'' (short for
``babyfaces,'' i.e., ``good guys'') and ``heels'' (``bad guys''). Between any
pair of professional wrestlers, there may or may not be a rivalry. You are given
the names of $n$ professional wrestlers and a list of $r$ pairs of wrestlers for
which there are rivalries. Give an $O(n + r)$-time algorithm that determines
whether it is possible to designate some of the wrestlers as faces and the
remainder as heels such that each rivalry is between a face and a heel. If it is
possible to perform such a designation, your algorithm should produce it.

\Solution

\begin{itemize}
    \item Create a graph $G = (V, E)$ where each wrestler is represented by a
    vertex and each rivalry is represented by an undirected edge.

    \item Use \textsc{Breadth-First Search} to traverse the graph. If the graph
    is disconnected, repeat the process for each unvisited node to ensure all
    components are processed.
    
    \item During the BFS, assign a distance to each vertex. Designate wrestlers
    at even distances as \textbf{faces} and wrestlers at odd distances as
    \textbf{heels}.
    
    \item Finally, traverse all edges $(u, v) \in E$ to verify that no two
    wrestlers of the same type (e.g., face-face or heel-heel) share an edge. If
    such an edge exists, a valid designation is impossible.
\end{itemize}
