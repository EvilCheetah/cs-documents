\item[\textbf{Problem 8}]
\textbf{Lab Task: Exploring AES-CBC Encryption Using OpenSSL}

In this lab, you will explore encryption using OpenSSL. First, ensure you have
OpenSSL installed. If you are using Linux or macOS, OpenSSL is usually
pre-installed; you can check by running \textbf{openssl version}. If it is not
installed, use \textbf{sudo apt install openssl} (Ubuntu) or \textbf{brew
install openssl} (macOS). On Windows, download OpenSSL from
\url{https://slproweb.com/products/Win32OpenSSL.html} (Or using WSL on Windows)
and follow the installation instructions. Once installed, verify by running
\textbf{openssl} version in the terminal or command prompt.

\textbf{Tasks:}
    \begin{enumerate}
        \item \textbf{Basic Encryption and Decryption}
        \begin{itemize}
            \item Use OpenSSL to encrypt a text file (\texttt{message.txt}) with
                  AES-256-CBC encryption using a password.

            \item Decrypt the file and verify the content.
            
            \item Provide a screenshot of the commands and output.
        \end{itemize}

        \item \textbf{Encrypt and Decrypt Using a Key File}
        \begin{itemize}
            \item Generate a random encryption key using OpenSSL and save it to
                  a file.
            
            \item Use this key to encrypt \texttt{message.txt} and decrypt it
                  back.
            
            \item Show the encryption key, encrypted file, and decrypted file in
                  a screenshot.
        \end{itemize}

        \item \textbf{Observing Encrypted Data}
        \begin{itemize}
            \item Encrypt \texttt{message.txt} using AES-256-CBC and then open
                  the encrypted file in a text editor.
            
            \item Compare the original and encrypted content, then describe your
                  observations.
        \end{itemize}
    \end{enumerate}
